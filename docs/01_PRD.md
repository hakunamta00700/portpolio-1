# 제품 요구사항 정의서 (PRD)

## 1. 프로젝트 개요

### 1.1 제품명
**ReserveOS** - 소상공인을 위한 브랜드 예약 관리 시스템

### 1.2 배경 및 목적
- 네이버 예약, 카카오 예약은 플랫폼 수수료 발생 및 브랜드 독립성 부족
- 소상공인이 자신의 브랜드 도메인으로 예약 시스템을 운영할 수 있도록 지원
- 개발 에이전시 포트폴리오로서 실제 사업 가치를 증명하는 프로젝트

### 1.3 타겟 고객
- 카페, 식당 (테이블 예약)
- 헤어샵, 네일샵, 피부과 (시술 예약)
- 소규모 강의, 상담 서비스 (1:1 예약)

---

## 2. 사용자 역할

| 역할 | 설명 |
|------|------|
| **고객 (Customer)** | 예약 페이지에서 날짜/시간/서비스를 선택하여 예약하는 최종 사용자 |
| **사장님 (Owner)** | 업체를 등록하고 예약을 관리하는 사업자 |
| **직원 (Staff)** | 사장님이 추가한 직원, 본인 담당 예약만 확인 가능 (선택 기능) |

---

## 3. 핵심 기능 요구사항

### 3.1 고객용 예약 페이지 (Customer-facing)

#### [필수] CUS-01 업체 프로필 조회
- 업체명, 소개, 위치, 영업시간 표시
- 업체 고유 URL로 접근 가능 (예: `reserveos.kr/hairshop-hong`)

#### [필수] CUS-02 서비스 선택
- 업체가 제공하는 서비스 목록 표시 (이름, 소요시간, 가격)
- 서비스 선택 후 예약 진행

#### [필수] CUS-03 날짜/시간 선택
- 달력 UI에서 예약 가능한 날짜 선택
- 선택한 날짜에서 예약 가능한 시간 슬롯 표시
- 이미 예약된 슬롯은 비활성화

#### [필수] CUS-04 예약자 정보 입력
- 이름, 연락처(휴대폰), 요청사항(선택) 입력
- 회원가입 없이 예약 가능 (비회원 예약)

#### [필수] CUS-05 예약 확인 및 완료
- 예약 내용 최종 확인 페이지
- 예약 완료 후 예약번호 발급
- 이메일 알림 발송 (MVP)
- SMS / 카카오톡 알림은 Phase 2 (별도 외부 API 연동 필요)

#### [선택] CUS-06 예약 취소
- 예약번호 + 연락처로 본인 예약 조회
- 업체 설정 취소 정책 내에서 취소 가능

---

### 3.2 사장님 관리 대시보드 (Owner Dashboard)

#### [필수] OWN-01 업체 등록 및 설정
- 업체명, 소개, 주소, 연락처, 영업시간 설정
- 업체 고유 슬러그(URL) 설정
- 로고/대표 이미지 업로드

#### [필수] OWN-02 서비스 관리
- 서비스 추가/수정/삭제 (이름, 가격, 소요시간, 설명)
- 서비스 활성화/비활성화

#### [필수] OWN-03 예약 현황 조회
- 오늘의 예약 목록 (타임라인 또는 리스트 뷰)
- 주간/월간 예약 달력
- 예약 상태 표시: 대기중 / 확정 / 완료 / 취소

#### [필수] OWN-04 예약 관리
- 예약 상세 조회 (고객 정보, 서비스, 시간)
- 예약 확정 / 취소 처리
- 관리자 메모 추가

#### [필수] OWN-05 가용 시간 관리
- 영업일 및 영업시간 설정
- 특정 날짜 휴무 설정 (공휴일, 임시 휴무)
- 시간 슬롯 단위 설정 (30분, 1시간 등)

#### [필수] OWN-06 알림 설정
- 신규 예약 발생 시 사장님에게 알림 (이메일 또는 카카오톡)
- 예약 확정 시 고객에게 알림

#### [선택] OWN-07 통계
- 기간별 예약 건수, 매출 현황
- 인기 서비스, 인기 시간대 분석

## 4. 비기능 요구사항

### 4.1 성능
- 고객 예약 페이지 초기 로딩 3초 이내
- 예약 가능 시간 슬롯 조회 1초 이내 응답

### 4.2 보안
- 사장님 계정 인증 필수 (Supabase Auth / JWT)
- 고객 개인정보(이름, 연락처) 암호화 저장
- HTTPS 강제 적용

### 4.3 반응형 디자인
- 모바일 우선(Mobile-first) 설계
- 고객 예약 페이지: 모바일 최적화 필수
- 관리 대시보드: 태블릿/데스크탑 최적화

### 4.4 확장성
- 멀티 업체 지원 구조 (한 계정에 여러 업체 등록 가능)
- 향후 결제 모듈 연동을 고려한 DB 설계

## 5. 포트폴리오 어필 포인트

1. **비즈니스 가치 명확**: "수수료 0원, 내 브랜드 URL"
2. **실제 사용 가능한 완성도**: 단순 UI 데모가 아닌 실제 동작하는 시스템
3. **기술 스택 현대성**: Next.js 14 App Router, Supabase, Docker
4. **개발/운영 환경 분리**: Docker Compose로 로컬 개발, Vercel+Supabase로 배포
5. **반응형 UX**: 소상공인 타겟에 맞는 직관적인 인터페이스

## 6. 개발 범위 (MVP)

- 모바일 앱
